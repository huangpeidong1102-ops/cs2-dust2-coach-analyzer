# CS2 Demo 分析器（沙二 de_dust2 教练版）

一个完全本地运行的沙二复盘工具：上传 `.dem` → 选择玩家 → 逐回合给出选位、配合、决策、准星四项评分，并用教练口径解释“这次死亡到底值不值”，而不是简单按死亡次数扣分。

新版重点：

- **资深教练总评仪表盘**：报告顶部不再只是数字罗列，而是一位教练的整场诊断——球员风格画像（突破手/狙击手/团队型步枪手/稳健 Anchor/全能自由人 + 道具位/补枪手副标签）、一段人话总评、场均评分环，以及六张职业指标卡（K/D/A、ADR 场均伤害、KAST 回合贡献、首杀/首死与成功率、爆头率、存活率），每项都带全场 10 人排名。
- **状态曲线与关键回合**：逐回合总分折线（金线）+ 5 回合移动均值（白虚线）+ CT/T 底色分段，点击任意点位跳到该回合；下方自动挑出最值得回看的 5 个关键回合（eco 翻盘 / 强起翻盘 / 独活残局 / 多杀 / 最佳 / 最差），手枪局单独归类、不误判为 eco 翻盘。
- **强项短板 + 分级训练计划**：教练认可的强项与优先解决的短板各列 3 条（带证据），训练清单按 P0 立即改 / P1 重点练 / P2 长期保持分级排序。
- **对手侦察**：像教练一样研究对面——识别对方击杀王 / 突破手（首杀最多）/ 狙击手（AWP 击杀），统计对手进攻偏爱 A/B 区及胜率，并给出针对性布防建议（交叉火力反制 entry、烟闪逼 AWP 换位、向偏好区倾斜防守）。
- **每回合教练解说**：教练卡新增一段因果叙事（开局意图→第一接触→下包/回防→结局与你的贡献），把回合讲成故事而不是模板判词。
- **进攻路线胜率 + 心态韧性**：T 侧开局 20 秒落位归类为 A大/A小/B洞/中路，统计各路线胜率条形图；并计算连败≥2 局后的场均分与全场均值对比，评估逆风心态。
- **地图点位重新校准**：匪家/警家/A包点/B包点四个锚点用真实 demo 的出生点与下包事件实测校准，其余点位按标准 callout 图标定并经可行走面掩膜校验，修正了旧版中路/中门/B洞/A大等点位的偏移。
- **胜负与比分来自真实事件**：直接读取 demo 的 `round_end` 事件（胜方 + 获胜原因），总览显示大比分 T:CT，回合标题标注胜/负，时间轴末尾有“回合结束”条目；不再靠死亡快照猜测胜负。
- **统计只算正式交火时间**：买枪冻结期（站出生点、准星水平）和回合结束后的庆祝/走路时间全部剔除，头线率、存活时间、补枪距离不再被灌水；击杀/死亡与 demo 事件逐条核对一致。
- **左右双栏复盘**：左边地图、右边侧栏（道具 / 经济 / 时间轴 / 准星 / 复盘五个选项卡）。点击右侧任意一条道具，地图自动跳到爆开瞬间、金圈标出落点并显示当时轨迹；时间轴事件同样可点击跳转。
- **全场颜色代号**：除了开局选玩家，报告里不再出现玩家名——CT=蓝（蓝CT①…）、T=红（红T①…），你=金圈+“(你)”标记，编号跨回合稳定。地图上的你带金圈和“你”字标签。
- **每回合比分全程可见**：回合导航每个芯片底部显示该回合结束后的累计比分 T:CT，回合标题、教练判词上方都有“本回合后比分”，时间轴“回合结束”条目也带比分，一眼看清局势是怎么走到 11:12 的。
- **经济分析（新增）**：读取 demo 的购买明细与每回合存款，按 MR12 竞技现行规则重建收入（胜负奖励、击杀奖励、连败补偿、下包/拆包、CT 击杀全队奖励），判断你与队友的起枪档位（纯经济/半起/全起），估算阵亡装备损失，并给出“别独起、别独 eco、全起阵亡输回合要讲交换价值”等经济建议；总览新增总消费、阵亡装备损失、eco 局胜率、每千元伤害。
- **每回合三条建议**：教练判词下方新增“选位”“道具”“经济”三条具体建议（孤点改交叉位、突破先给闪、被白先退掩体、起枪先看队友经济等）。
- **准星玫瑰图升级**：八方位标签与地图方位一致，中心显示主看方向，悬停任意扇区看采样数/占比/平均俯仰，并配一段人话总结（头线、主看方向、最大未看空档、贴墙问题）。
- **操作优化**：回合导航吸顶+上一回合/下一回合按钮，回放支持 0.5×–4× 倍速，快捷键空格播放/暂停、←/→ ±1 秒、Shift+←/→ ±5 秒；上传与选人在分析后折叠成一条，可随时展开更换。
- 教练式**交换价值**：防守方一换一不一定好，要看换完之后防线还剩几个人；进攻方首死也不一定差，抢下点位、吸出枪线、快速下包都可能是有价值首死。没换到人但队友 6 秒内反杀其他敌人，会判“延迟反杀（交换部分成立）”，不再一律按普通阵亡扣分。
- **存活价值**单独判断：下包后活着、包点失守后保枪、残局保枪、赢下回合存活，分数完全不同。存活/保枪判断按回合结束时刻的真实位置和真实存活人数计算（旧版会误用下回合出生点位置）。
- **雷达墙体近似**：用沙二可行走面提取二维遮挡，判断准星是否贴墙、两人之间视线是否被墙切断。只能近似，不能区分上下层和可穿透物。
- **时间窗准星审查**：任意选一段回合时间，看准星方向密度、头线率、贴墙率、视线撞墙比例，并生成 24 格方向玫瑰图。
- **人物朝向 + 开火弹道**：雷达上每个人物有朝向箭头，开火时画出子弹方向；轨迹只显示已走过部分，后段保留淡影。
- **1:1 实时回放**：64 tick = 1 秒，按真实回合耗时播放，不是固定帧动画。
- **赛后训练清单**：从全场共性里挑 3 个最值得练的点，每个都给出“为什么”和“怎么练”，并可直接跳回对应回合。
- 只针对 **de_dust2**，不做其他地图。

## 一、如何启动

1. 双击 **`启动分析器.bat`**（首次运行会自动准备环境，需联网装依赖，之后无需联网）。
2. 浏览器会自动打开 `http://127.0.0.1:8765`。
3. 把 `.dem` 文件拖进上传区（或点“选择文件”），等待解析。
4. 在下拉框选择要分析的玩家，点“开始解析”，查看总体表现和逐回合报告。

> 关闭服务：直接关掉黑色命令行窗口。上传的 demo 存放在 `uploads/`，可自行删除。
> 地图数据按回合按需加载，22 回合的 demo 首屏不会一次塞进十几 MB 数据。

## 二、demo 从哪里来

- 5E 平台 demo 一般在 `C:\Users\<用户名>\AppData\Roaming\5E对战平台\demo\`（压缩包需先解压出 `.dem`）。
- 官方匹配 demo 在 Steam 目录的 `Counter-Strike Global Offensive\game\csgo\replays\`。
- 仅支持 CS2 格式（文件头为 PBDEMS2）；热身回合会自动跳过。
- 已用两份不同来源的 de_dust2 demo 做过回归：5E 平台 demo 和 Valve 官方匹配 demo；空事件、空阵营字段、NaN 坐标都不会让分析崩掉。

## 三、教练口径：先看结构，再看数字

### 1. 交换价值（重点）

同样是 1 换 1，结论可能相反：

- **有效一换一（后续防线稳）**：你换掉一人，且死后至少还有两名队友在防线结构里，没有被连锁打穿。
- **换命后仅剩单人防线（价值有限）**：你换掉一人，但倒下时队里只剩一名队友；这次交换只止血，没有保住防线厚度。
- **低价值一换一（后续被打穿）**：数字上是 1 换 1，但你死后队友连续掉点或包点很快失守。
- **可交换锚点 / 单人防线补枪**：你没拿到击杀，但队友能立刻补掉杀手；是否加分取决于补完之后还剩几个人。
- **延迟反杀（交换部分成立）**：你没换到人、也没被立刻补枪，但队友在 6 秒内反杀了其他敌人，人数没有继续恶化——按打平处理，不再误判成普通阵亡。
- **残局阵亡**：队友已全部阵亡，不再按普通脱节阵亡重罚；拿人头值得肯定，但不能用“后续队友”来要求你。
- **进攻方首死**：
  - `抢点型首死（有价值）`：死在进点/要道，吸住防守枪线，队友拿到击杀或 12 秒内快速下包。
  - `抢点型首死（价值有限）`：死在要点附近且队友压上，但没有立刻换到人头或下包。
  - `换命首死（有后续收益）`：第一个接触并换掉防守方，队伍没有因此断节奏。
  - `无效首死`：没有换人、没有补枪、没有下包或站点控制。

### 2. 存活价值

- T 下包后存活：正分，能继续守包/接应。
- CT 赢下回合并存活：正分。
- T 队友全灭且没下包时保枪：正分，避免多送一条枪。
- CT 包点已经失守还远距离保枪：负分，属于过度保守。
- 普通存活只给小幅正分，不会因为“没死”就自动高分。

### 3. 四项评分

每回合仍给 0–100 分和评级（优秀/良好/一般/失误），但决策分已经纳入交换价值与存活价值：

- **选位**：与最近存活队友的距离、是否可被补枪、是否站在要道/包点结构里。
- **配合**：4 秒内补枪、你死后队友是否反打、全队补枪距离。
- **决策**：开局/中盘/下包后/残局阶段，双方人数，是否该找人、该退、该保枪。
- **准星**：交火角度偏差、头线保持、要道预瞄、阵亡瞬间准星到杀手的夹角。

### 4. 整场教练总评指标口径

仪表盘的职业指标全部由 demo 真实事件推导，不编造：

- **ADR（场均伤害）**：总伤害 ÷ 回合数，衡量输出火力；附全场 10 人排名。
- **KAST（回合贡献率）**：一个回合里你只要有「击杀 / 助攻 / 存活 / 被补枪」任意一项就算有贡献，KAST = 有贡献回合 ÷ 总回合。职业队常用它衡量“是否隐身”，比单纯 K/D 更能反映团队价值。补枪认定窗口为你阵亡后 4 秒内队友击杀你的杀手。
- **首杀 / 首死**：每回合第一个死亡事件的杀手/受害者；首杀成功率 = 首杀 ÷（首杀+首死）。
- **爆头率**：你的击杀中爆头占比，反映击杀质量。
- **存活率**：存活回合占比。
- **风格画像**：按 AWP 起枪占比、首杀首死比例、存活率、与队友平均距离、道具使用量等行为数据打标签，是数据驱动的近似，不是唯一定论。
- **关键回合**：eco/强起翻盘、独活残局、多杀、最佳/最差回合；手枪局是独立战术回合，不计入 eco 翻盘口径。

### 5. 对手侦察 / 叙事 / 路线 / 心态口径

- **对手侦察**：逐回合取与你相反阵营的玩家聚合击杀/首杀/AWP 击杀/伤害；击杀王=总击杀最高、突破手=首杀最高、狙击手=AWP 击杀最高（≥2 才列出）。进点偏好只统计你打 CT 时对手（T）的下包区与赢球数。建议为规则化布防思路，供参考。
- **教练解说**：由本回合真实事件（你的道具、首杀/首死、下包/拆包/引爆、胜负与贡献）按时间顺序拼成因果叙事，不引入事件之外的推测。
- **进攻路线**：仅统计 T 侧；取开局后第 20 秒你的位置归类到 A大/A小/B洞/中路（样本≥2 回合才显示），胜率=该路线赢球÷回合数。
- **心态韧性**：连败≥2 局之后那些回合的场均分，与全场均值对比；≥+3 判"越挫越勇"、≤-6 判"逆风掉状态"，其余为稳定。样本<2 不评估。

## 四、死亡复盘与更优解

每个死亡回合都会列出：

- 死亡时间、地点、杀手位置与距离、武器/爆头/烟中击杀；
- 准星偏差、死亡瞬间准星到墙距离、两人视线是否被雷达墙切断；
- **死亡瞬间所有存活队友和敌人的位置与距离**；
- 一句“死亡位置全景”，直接说明你倒下时队友在哪、敌人在哪、谁最近；
- 一条具体更优解：退向最近队友、先让队友架补枪角度、残局用地形逼先手、不要在无接应时拉大身位等。

好回合也会写“为什么好”，例如：有效一换一后续防线没崩、残局换到人头、下包后存活、闪光实际白到多人、补枪及时。

## 五、地图、墙体与弹道

- 底图为 1024×1024 沙二雷达，标定 `pos_x=-2476`、`pos_y=3239`、`scale=4.4`。
- **点位校准**：匪家/警家/A包点/B包点四锚点取自真实 demo 的冻结期末出生点与 `bomb_planted` 下包位置（多回合中位数，抗换边离群）；中路/中门/A大/A小/B洞等其余点位按标准 callout 图（csbepro、skin.land、win.gg）相对布局标定，并逐点经可行走面掩膜校验落在可通行区域内。换 demo 时雷达标定不变，点位通用。
- 颜色代号：蓝=CT、红=T、金圈+“你”字=分析目标；你的轨迹为金色，死亡点 ×、下包点黄块。文字报告里同样用 蓝CT① / 红T② / (你) 代替玩家名。
- **墙体层**：点“显示墙体”后显示红色墙体轮廓（只画墙体边缘，不整片盖住雷达）。墙体来自“可行走面雷达”提取的二维掩膜，适合判断准星是否贴墙、两人之间是否有隔墙；不区分上下层、箱子高度和可穿透物。
- **人物朝向**：每个存活人物都有朝向箭头，箭头方向来自 demo 的 yaw。
- **开火弹道**：开火事件按真实位置和 yaw 画出子弹方向；当前时刻最近 1.5 秒全队弹道较亮，时间窗内分析目标的弹道用淡黄色保留。
- **轨迹**：全场轨迹保留淡影，已经走过的部分高亮，方便看“当时走到了哪”。
- **1:1 回放**：`▶ 1× 实时回放` 按 64 tick/秒推进，时间轴上的秒数与真实回合时间一致。

## 六、时间窗准星审查

1. 选择回合后，默认选中“死亡前 10 秒”；存活回合默认选中“回合结束前 10 秒”（不含赛后时间）。也可点按钮重置。
2. 拖动起点/终点两个滑块，选择任意时间窗。
3. 玫瑰图显示准星在 24 个 15° 方向上的密度，**八方位标签与地图方位一致**（右=地图右方）；中心圆显示这段时间的“主看”方向，黄线是窗口末的准星方向。
4. **鼠标悬停任意扇区**：显示该方向的采样次数、占比、平均俯仰角；没看过的方向会标红提醒。
5. 图下方先给一段**人话总结**（头线保持、主看方向、最大未看空档、贴墙问题），再列指标：
   - 头线率：无接触时俯仰角 ≤6° 的比例，即准星放在敌人头部高度的时间占比；
   - 视线遇墙：采样射线在 1200 单位内遇到墙体的比例；
   - 准星贴脸墙（<2m）：射线在 80 单位内撞墙的比例；
   - 俯仰异常、看过的方向格数。
6. 颜色含义：浅青=常看方向，亮青=主要方向，红=该方向平均俯仰异常，暗红=整段没看。

> 这些指标是“准星摆放”的近似体检，不是要求每个角都必须瞄头线；架枪位本来就该只盯一个方向，未看方向交给队友覆盖即可。

## 七、赛后训练清单

报告顶部会按影响面排序给出最多 3 条训练建议，例如：

- 一换一之前，先看换完之后还剩几个人；
- 减少无接应的第一接触；
- 准星高度与离墙距离；
- 把“补枪”变成默认动作。

每条包含“为什么”（用本场回合数与证据说话）、“怎么练”（可执行的动作）和“回看”按钮，点一下直接跳到对应回合。

## 八、经济分析与比分规则

### 1. 逐回合比分

比分按 demo 的 `round_end` 胜方逐回合累加，半场（第 12 回合后）换边、加时按 MR3 继续累加。回合芯片、回合标题、教练判词、时间轴末尾都显示“T:CT”累计比分，方便对照每一回合的决策对局势的影响。

### 2. 采用的经济规则（MR12 竞技现行版本）

- **开局与上限**：半场开局每人 $800，存款上限 $16000；加时（MR3）开局 $10000。
- **回合胜利奖励**：歼灭 / CT 拖时间胜 $3250；引爆 / 拆包胜 $3500。
- **连败补偿阶梯**：$1400 / $1900 / $2400 / $2900 / $3400。连败计数半场初为 1，输一局 +1（封顶 4），赢一局 -1（保底 0）；所以输掉手枪局拿 $1900。
- **击杀奖励**：刀 $1500；多数霰弹枪 $900；XM1014 与除 P90 外的冲锋枪 $600；步枪 / 手枪 / P90 / SSG08 / 投掷物 $300；AWP 与 Zeus $100。
- **目标奖励**：下包 / 拆包个人 +$300；T 下包后仍输回合每人 +$600（CS2 由 $800 下调）；2025-07 起 CT 每击杀一名 T，全队 +$50。
- **起枪档位**：按冻结期末主武器 + 本回合消费 + 上回合保枪结转，分为纯经济 / 半起（强起）/ 全起；手枪局默认手枪。

### 3. 经济面板看什么

- 顶部：你的起枪档位 + 主武器 + 本回合后比分。
- 四宫格：本回合消费、买枪后存款、回合结束存款、护甲/道具件数。
- 收入明细：胜负奖励、击杀奖励、连败补偿、下包/拆包、CT 击杀全队奖励、T 下包仍输奖励；阵亡时单列“装备损失（估算）”。
- 团队起枪：4 名队友的全起/半起/纯经济分布，若你与团队档位脱节会给出警告。
- 连败计数与“若下回合再输可拿 $X”，帮你判断该 eco 还是该强起。
- 总览经济项：总消费、阵亡装备损失、eco 局胜/eco 局数、每千元伤害（伤害÷消费×1000，衡量花钱效率）。

### 4. 口径与局限

- 起枪档位按“冻结期末主武器 + 消费”近似判断；该 demo 解析版本拿不到精确装备价值字段，故装备损失按本回合消费估算（阵亡≈丢掉本回合所买）。
- 武器名做了归一化：去 `weapon_` 前缀、皮肤前缀（如 `5e_2024pass3_ak47`→AK-47）、消音器别名（m4a1_silencer→M4A1-S、usp_silencer→USP-S）。
- “T 输时间局存活者拿 $0”等极细分规则未计入，仅规则说明提及。
- 经济规则来源（2026 现行版本，多源交叉确认；旧指南的过时数值已弃用）：
  - https://onlyfarms.gg/wiki/counter-strike-2/economy-buy-rounds-weapons-glossary
  - https://cs2pedia.com/guides/cs2-economy-guide/
  - https://gamertagmythras.com/blog/counter-strike-2/cs2-economy-guide

## 九、已知局限（请理性看待）

- 墙体是**二维雷达近似**，不是游戏内真实碰撞网格；上下层（如 A 平台/大坑）、箱子、可穿透物无法区分。A 大/A 小等自动锚点也可能落在掩膜边缘，报告会标注“近似”。
- 墙体轮廓来自公开可行走面雷达，和官方雷达有轻微边界差；只用于“是否贴墙/是否隔墙”的粗判，不用它判断子弹能否穿过。
- 教练判词是规则化建议，适合复盘参考，不能替代真人教练；同一回合可能存在多个合理解法。
- 道具战术基于时间、点位和结果识别，不等于读取队伍语音。
- 该数据源个别 demo 没有闪光弹投掷 `weapon_fire` 记录，投掷点会按爆点前约 90 tick 的位置估算，界面标注“估算”；爆点、致盲和伤害仍是真实事件。
- 只支持 de_dust2；换图后点位命名会失效。
- 本版统计口径与旧版不同（剔除冻结期/赛后时间、胜负改为事件驱动），同一份 demo 的分数与旧版不完全一致，属预期；击杀/死亡总数已与 demo 原始事件逐条核对。

## 十一、参考的教练思路

判词口径参考了公开的 CS2 沙二教学讨论，主要包括：

- 防守不是蹲点，要制造不可预测的第二枪位，并考虑上下枪位和常规闪光；
- 沙二 CT 非预瞄站位，目标是让敌人恰好露侧身、能一换多；
- 防守选位要看大坑贴墙、蓝箱双架、高箱等具体点位；
- 选位避免过常规，B1/A 小可以准备非常规点；
- A 大防守三身位协同，第一身位丢火拦后续补枪；
- 突破手/补枪手两套思路，依据队友站位和对手道具切换；
- 偷首杀要安全高效，不是自爆流；
- 准星摆放：近快远慢、直角离墙远、斜角离墙近，准星可以穿墙预瞄但注意力在墙后；
- 直角架枪至少一个半身位，斜角一个身位；贴墙外侧边缘平移，过点放到烟边。

这些是公开教学观点，工具只把它们转成可计算的规则，不代表唯一正确打法。
